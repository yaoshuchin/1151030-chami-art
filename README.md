## ✨ 核心特色

1. **完整典藏**：
   - 典藏全班 26 位創作者共 189 件作品。
   - 本地完整備份 181 張高清作品圖像，不隨雲端預簽名網址過期而失效。
   - 完整保留學生留言討論與愛心反饋。

2. **精美現代化介面**：
   - 支援 **網格模式 (Grid)** 與 **瀑布流 (Masonry Columns)** 排版切換。
   - 支援 **深色模式 (Dark)** 與 **淺色模式 (Light)** 隨心切換。
   - 學生個人化色彩頭像標章。

3. **強大互動功能**：
   - **全文即時搜尋**：可搜尋學生姓名、作品標題、說明或留言內容。
   - **作者快速篩選**：下拉選單快速篩選指定同學的所有作品。
   - **多維度排序**：支援原始順序、最多愛心、最多留言、作者姓名排序。
   - **本地互動點讚**：支援即時點擊愛心互動。
   - **作品全螢幕燈箱 (Lightbox)**：
     - 高清全螢幕放大預覽。
     - 支援放大、縮小、重設比例縮放工具列。
     - 一鍵下載原圖。
     - 鍵盤快速鍵導航（`←` / `→` 切換作品，`Esc` 關閉）。

## 📂 檔案目錄結構

```text
├── index.html          # 主頁面（含密碼鎖定 Gate 與展覽主看板）
├── style.css           # 現代化響應式樣式表（含深色/淺色主題變數）
├── app.js              # 前端交互邏輯、密碼驗證、燈箱與搜尋排序
├── posts_data.js       # 結構化作品資料（防跨域獨立打包）
├── images/             # 181 張原創學生作品本地高清圖片庫
├── data/               # 完整 JSON 結構備份資料
├── crawl_all.py        # 爬蟲與資料擷取腳本
└── process_data.py     # 資料清洗與標準化處理腳本
```
